# Refonte UI/UX — l'Éduc de Normandie (Page d'accueil)

Proposition de refonte graphique et d'harmonisation de la page d'accueil de l'ENT **l'Éduc de Normandie**, conçue dans la continuité de la nouvelle page de connexion.

## 🔗 Démonstration
* **Prototype en ligne :** [Voir le site](https://y9ueve.github.io/refonte-educ-normandie/)

## 🎯 Objectifs
* **Cohérence visuelle :** Aligner l'accueil avec la nouvelle identité graphique officielle.
* **Ergonomie :** Améliorer le confort de navigation sur mobile et ordinateur.

## 🛠️ Stack technique
